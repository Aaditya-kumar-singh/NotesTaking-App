## Must fix or provide missing acceptance evidence before final approval

1. **NP-084: Native manifest validation is incomplete.** SafeFileWriter.hasNativeManifest only checks manifest.json ZIP entry presence and nonzero size, not JSON parse or CRC. A ZIP with malformed manifest JSON and valid central directory is accepted for metadata-only SessionStore/CanvasSessionStore saves. Tests reject missing entries but not a malformed present manifest; require actual decode/CRC validation before acknowledging a native snapshot.

2. **NP-074: Editable PDF export cannot be selected in the app.** PdfExporter supports optional PDAnnotationInk but PageExportDialog/MainActivity have no localized selectable editable-PDF option wired into editableInkAnnotations=true. The backend implementation is partial, and coordinator-owned UI/SAF route is needed for user-visible acceptance.

3. **NP-098: Split-pane divider touch target remains too narrow.** ToolbarFrame now budgets pinned controls, but coordinator-owned MainActivity defines DIVIDER = 16.dp. The feature asks for divider resizing without canvas gestures or wrong-pane switches and proper touch accessibility. A 16dp divider is not a 48dp touch target; requires coordinator fix and device tests.

4. **NP-100: Save and Export retry acceptance not covered by this handoff.** The B-owned change pins infinite canvas render/GL error warnings, but the task also requires clear retry and no false successful Save/Export on provider failure. That behavior was not demonstrated by this toolbar-only change; coordinator cross-lane source and real SAF/device QA required.
