## Design intent

Make it immediately clear how to create a note: name it, inspect the paper/cover preview, choose a page size and orientation, pick a template, customize it if desired, then create. The visual direction remains **Modern Paper & Ink** with existing Material 3 and theme palette roles. The existing tablet two-pane editor stays intact when the available pane is at least 720dp wide and 600dp tall. Landscape phones and short multi-window panes use the stacked layout rather than clipping the side-by-side preview.

## User-facing improvements

- **Preview is visibly labelled** on phone and tablet, without changing existing actual paper/cover previews, selection, live rendering, or template cache behavior.
- **Paper size and orientation** now have an explicit section label. The page-size drop-down and custom mm fields use 48dp-high controls; mm inputs grow to 80dp width. Portrait/Landscape are labelled as well as illustrated, with at least 48dp height, 112dp minimum width, and selected-state semantics. Custom validation and portrait/landscape dimension swapping are preserved.
- **Template gallery** is clearly identified as “Paper and cover templates,” or “Generate using AI” when that tab is active. The Pages, Cover and AI tabs remain present and scroll horizontally if narrow; none are silently removed.
- **Selected templates** use accent-colored names at 13sp for readability, in addition to the pre-existing selected outline and checkmark. Imported templates, template removal menus, colors, AI templates and note covers remain available.
- **Mobile Customize entry** is a minimum 64dp-tall bottom strip with a recognizable settings icon. It opens the same existing customization sheet, not a second editor.
- **Creation state protection:** Create (and Done in cover-only mode) is disabled while busy; the busy indicator retains contrast, and the handler rejects duplicate taps. Invalid custom dimensions still disable creation, with the prior range warning retained. Tablets use the clearer action label “Create note”; narrow phones keep “Create” to preserve room for the note title.
- English and Simplified Chinese strings were added without changing the existing translation or theme engines.

## Exact source scope

- `app/src/main/java/com/notestaking/app/ui/NewNoteScreen.kt`: Compose layout and interaction affordances only.
- `app/src/main/res/values/strings.xml` and `values-b+zh+Hans/strings.xml`: Section headings and creation label.

No modifications to document schemas, template import/export or serialization, cover editing callback, creation callback data, PDF conversion, page dimensions, inking algorithms, backups, settings storage, fonts, package IDs or license notices.
